# Доступность (a11y) — RideAuto web

## Гейты в CI

| Проверка | Команда / job |
|----------|----------------|
| axe (serious/critical) | `npm run test:e2e:a11y` → job `web-a11y` |
| Bundle gzip | `node scripts/check-bundle-budget.mjs` после `npm run build` → job `next-build` |
| Lighthouse | `npm run lh:ci:*` → job `next-build` |
| Storybook a11y addon | предупреждения в dev (`test: warn`) |

## Ручная проверка

1. **Клавиатура:** Tab с главной → skip-link → навигация → каталог → фильтры → карточка.
2. **Экранный диктор:** landmarks (`header`, `nav`, `main`, `aside`, `footer`), `aria-live` на результатах каталога.
3. **Контраст:** тёмная/светлая тема, чипы фильтров, кнопки CTA.
4. **Уменьшенное движение:** `prefers-reduced-motion` — каталог без virtual list, без лишних анимаций.

## Паттерны в коде

- `SkipLink` → `#main-content` в `SiteShell`
- Фильтры: `aside[aria-labelledby="catalog-filters-heading"]`
- Результаты: `section` + `aria-live` для статуса загрузки
- Мобильное меню: `aria-expanded`, `aria-controls`, Escape закрывает

## Добавление страниц в axe

Расширьте `e2e/a11y.spec.js` (тег `@a11y`). Порог: только `serious` и `critical` (не весь WCAG noise).
